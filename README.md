# Beisi Docs

倍司科技的博客与文档仓库。

## 内容架构

这个仓库里的博客和文档承担不同的作用。

- **博客**是随笔、杂谈和阶段性观点，用来记录当下的经历、观察与判断。它可以不完整，也允许以后发生变化。
- **文档**是从博客和实践中进一步提炼出的系统内容。它会去掉重复和情绪，整理成更稳定的概念、方法、流程与说明。

内容大致按下面的方式沉淀：

```text
经历、观察与想法
        ↓
博客：先把当下的观点写下来
        ↓
同类内容持续积累
        ↓
文档：提炼成系统、稳定、可复用的内容
```

博客不需要提前写成教程。等某个主题积累到需要系统整理时，再单独让 AI 读取相关博客和资料，重新编写文档。

## 目录

- `my-website/blog`：博客文章。
- `my-website/docs`：经过整理的项目、规范和教程文档。
- `BLOG_WRITING_PROMPT.md`：博客写作要求。
